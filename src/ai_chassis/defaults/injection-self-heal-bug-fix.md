/delegate {delegation_target} /bug-fix The /start-goal prompt injection into this session ({target_session}) failed {stage} validation: {description} (run {run_id}, failure signature {signature_human} = {signature}, reason {reason}, repair round {round} of {max_rounds}).
Investigate from the run's observability record at {run_record_path}: it holds the intended /goal text, every cursor-move capture of the walk, the stitched view, the pre-submission verdict, the typed and submitted text, the post-submission transcript view and verdict; the attempt record is {attempt_path} and the stage log lines are those with key={key}. Review the logging and observability features of ai_chassis.prompt_injection to investigate the root cause of the issue that allowed the prompt to pass pre-submission validation with prompt text missing or garbled, or that made post-submission validation fail, and fix that root cause so the pre-submission validation would have caught it. Also, make sure to update the logging and observability if there were any gaps missing there for this issue, as well.
Before substantive work, run /beads-task to create the shipped Beads issue for this repair round (title it with the signature {signature_human} and round {round}; link it to the previous round's issue: {previous_issue}) and create the matching CC task with TaskCreate, then TaskUpdate it to in_progress with an owner, so it shows on the task panel while the round is open; set the Beads issue in_progress too.
When it is fixed and tested and validated, merge it in via PR, reap the worktree, run /sync-git repo:{repo_main_tree} so the fix is on the main tree, and then run: python -m ai_chassis.prompt_injection self-heal mark-fixed --signature {signature} --commit <merge commit sha> --issue <Beads id> --pr <PR number>. That command verifies the fix is on the main tree and operational, re-arms /start-goal for this failure signature, and re-runs the pending /start-goal run itself; make sure the new fix is active for the /start-goal feature. Until it has run, nothing in this session retries the /goal injection and nothing launches a second /bug-fix for this signature.
