## Claude macOS profile

This overlay identifies a macOS developer host using the default POSIX shell. Confirm the active
repository before editing. Use the system Python only for bootstrap work and keep project tools in a
repository environment. Prefer Homebrew only when a system prerequisite is actually missing, and
check both Apple Silicon and Intel executable locations before modifying startup files.

Remote-login endpoints, personal home paths, and secret-manager coordinates are intentionally local.
