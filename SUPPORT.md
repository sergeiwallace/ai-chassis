# Getting help

ai-chassis is an alpha, community-supported project. Nobody is on call, and replies
are best effort.

| You want to | Do this |
| --- | --- |
| Ask how something works | Open a [Discussions](https://github.com/sergeiwallace/ai-chassis/discussions) thread if the tab is enabled, otherwise open an issue with the `question` label. |
| Report a bug | Open an issue with the bug report form. Say which release you used (`VERSION` at the repository root), your operating system, and how to reproduce it. |
| Request a feature | Open an issue with the feature request form. Describe the problem before the solution. |
| Report a security problem | Do not open an issue. Follow [SECURITY.md](SECURITY.md) and use a private advisory. |
| Report a conduct problem | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). |

Before you ask, check the [documentation guide](docs/README.md), the
[changelog](CHANGELOG.md) for what each release contains, and the open and closed
issues for the same question.

What is not supported: this is a source toolkit for adapting to your own setup. We
cannot debug your agent configuration, your hosting, or third-party tools, and a
component that is not in the current release is not available yet.
