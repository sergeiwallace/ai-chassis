# Autonomous Work Completion Format

Present a completion report that lets a reviewer decide what to do next.

```markdown
## Summary

### Delivered
- [concise outcome]

### Files changed
- [paths]

### Verification
- [commands and results]

### Remaining risks or decisions
- [items needing follow-up]

### How to verify manually
- [reproducible steps]
```

Separate completed work from remaining work. Report concrete evidence instead of a bare claim
that the change works.
