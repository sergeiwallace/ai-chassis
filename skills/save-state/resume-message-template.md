# Resume Message Template

Emit one fenced text block that gives the next session enough context to continue safely.

```text
Resume <session> (<role>). Read <memory pointers>. <repository> at <revision>; tree <state>.

STATUS
- <completed and verified work>

NEXT
1. <concrete next step>

DO NOT TOUCH / BLOCKED
- <ownership boundary or external dependency>

RULES
- <constraints the next session must honor>
```

Use repository-relative paths and generic identifiers in reusable examples. Include only current,
necessary state; do not record private branch names, accounts, people, or client policies.
